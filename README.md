Apply consistent backend engineering practices for maintainable, secure, and reliable services.

## Features

- Task-focused guidance and practical workflows.
- Examples and implementation recommendations.

## Installation

Copy the skill into your agent skills directory:

```bash
mkdir -p .claude/skills/backend-dev-guidelines
cp SKILL.md .claude/skills/backend-dev-guidelines/SKILL.md
```

## Usage

Ask your AI coding assistant to use **Backend Development Guidelines** when working on a related task. Follow the instructions in `SKILL.md`.
